About The Project

A full-stack, cloud-deployable Machine Learning application engineered for an Electronics & Communication Engineering (ECE) DevOps assignment.

🏏 Executive Project Summary

The India Cricket Team Performance Prediction System is an end-to-end Machine Learning web platform designed to analyze, benchmark, and predict the match performance of Indian international cricketers across Test, ODI, and T20I formats.

Built specifically for an ECE College DevOps Assignment, the solution demonstrates professional software engineering practices: modular Python Flask backend architecture, scikit-learn machine learning pipelines, responsive client-side Chart.js telemetry, Git version control, and serverless deployment on Vercel.

🎯 Primary Objective

Predict individual player impact scores (0–100) and compare squad performers using verified sports analytics models.

⚙️ Technology Stack

Python, Flask, Scikit-Learn, Random Forest, Pandas, NumPy, Joblib, HTML5, CSS3, JavaScript, Chart.js.

🚀 DevOps Delivery

GitHub version control, stateless serverless functions via Vercel WSGI bridge, and zero server file mutation.

⚠️ Academic Notice: Limitations of Synthetic Training Data

Real international cricket presents limited sample sizes for rare player-role/format combinations. To ensure continuous feature space generalization without over-fitting, a structured synthetic data augmentation pipeline was utilized as a statistical fallback. These synthetic points model realistic Gaussian boundaries across strike rates, boundaries, and bowling economy. They calibrate the non-linear regression manifold and are not represented as real future match outcomes.

DevOps Assignment Architecture

CI/CD & Serverless Deployment Pipeline

🐙 GitHub Version Control

All application source files, templates, scripts, and model serialization assets are tracked via a modular Git repository structure with standardized commit conventions.

▲ Vercel Serverless WSGI

Configured with api/index.py and vercel.json using @vercel/python. Runs as auto-scaling stateless cloud serverless execution functions.

💾 Stateless Client Storage

To adhere to serverless read-only file systems, prediction histories are stored securely in browser localStorage, preventing ephemeral server disk errors.
