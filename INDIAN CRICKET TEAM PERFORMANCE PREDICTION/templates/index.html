How The Prediction Engine Operates

A streamlined end-to-end Machine Learning pipeline designed for the ECE DevOps assignment.

1

Select or Input

Select any verified Indian cricketer (e.g., Virat Kohli, Jasprit Bumrah) or manually enter custom match metrics.

2

Feature Encoding

Inputs are mapped across 11 features including role, format, strike rate, averages, and boundary proportions.

3

Random Forest Inference

The 150-estimator ensemble model predicts the player's calibrated performance index (0–100 scale).

4

Insights & Persistence

Categorizes tier (Excellent, Good, Average, Needs Improvement) and saves results to browser localStorage history.
